# 참고자료 화면 — 분야별 1페이지 표 레이아웃

> 2026년 부안군 청년정책 시행계획 · 5개 분야 / 49개 사업 / 117억 6,882만 원
> 앞선 "탭 + 카드 리스트" 안 대신, **분야당 한 페이지씩 5장** 구성

---

## 왜 이 방식이 더 나은가

이 웹앱 전체가 이미 **화살표로 넘기는 프레젠테이션 구조**입니다. 참고자료만 스크롤 리스트로 만들면 조작 방식이 달라져서 진행 중에 어색해져요. 분야당 한 페이지로 가면 **같은 조작(←→)으로 일관되게** 넘길 수 있고, 빔프로젝터 투사 시에도 한 화면에 한 분야가 딱 떨어집니다.

```
[참고자료 진입]
  → P1 일자리 → P2 교육 → P3 주거 → P4 복지문화 → P5 참여권리
     ←──────────── 화살표 / 스와이프 ────────────→
                    [ESC 또는 닫기 → 원래 세션 복귀]
```

## 페이지 공통 레이아웃

```
┌──────────────────────────────────────────────────┐
│ ① 일자리                          13개 사업        │  ← 분야 헤더
│    청년 일자리 확대 및 창업 활성화                   │
│                                  20억 5,594만 원  │
│                                  전체의 17.5%      │
├──────────────────────────────────────────────────┤
│                                                  │
│           ② 사업 목록 표 (본문)                     │
│                                                  │
├──────────────────────────────────────────────────┤
│ 💡 ③ 이 분야에서 짚어볼 점 (한 줄)                   │
│                        ● ○ ○ ○ ○   1 / 5         │  ← 페이지 인디케이터
└──────────────────────────────────────────────────┘
```

**표 공통 컬럼 (4개 고정)**

| 컬럼 | 폭 | 비고 |
|---|---|---|
| # | 5% | 연번 |
| 사업명 | 50% | 신규 배지 인라인 표시 |
| 예산 | 22% | 우측 정렬, 억/만 원 단위 |
| 담당부서 | 23% | — |

재원(자체/보조)은 컬럼을 따로 두지 말고 **사업명 옆 작은 점 표시**(● 자체 / ○ 보조)로 처리하는 걸 권합니다. 5컬럼이 되면 모바일에서 깨져요.

## 마지막 페이지(P6) 추가 제안 — "그래서 뭘 바꿀까"

## 정렬 기준에 대한 메모

위 표들은 모두 **예산 큰 순**으로 정렬했습니다. 시행계획 원문 순서(부서별 배열)를 그대로 쓰면 큰 사업과 작은 사업이 섞여서 규모감이 안 잡혀요. 다만 원문과 대조하실 일이 있으면 정렬 토글(예산순 ↔ 원문순)을 넣어두시면 됩니다.

일자리 분야만 7번(9,340만)이 6번(9,200만)보다 예산이 큰데 순서가 뒤집혀 있으니, 코드로 옮기실 때 정렬 로직으로 처리하시면 자동으로 맞습니다.
